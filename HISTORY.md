# Commit history of the original repository

The repository was rebuilt on 2026-10-03 so that its commit metadata no longer
carried a personal email address. The original repository was kept, renamed and
made private, rather than deleted — this file is a copy of its log so the
record survives in the public repository too.

**Why this file exists.** Several of these messages are the only contemporaneous
record of where the app's sound effects came from and under what licence: the
per-file source URLs were lost when a build sandbox was reclaimed, and these
dated messages are what remains. `MARKET-READINESS.md` relies on them. Deleting
the history would have destroyed that, so it is preserved here.

Dates and messages are copied verbatim from the original repository. The author
of every commit was the repository owner.
